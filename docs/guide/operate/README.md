# Operate

Running one evaluation is a command. Running evaluation as a practice is these four pages.

- **[Track the work](tracker.md)** — issues, projects and initiatives: why you are evaluating
- **[Schedules & monitoring](schedules.md)** — run a scorecard on a cron, and notice when it moves
- **[Analysis & views](views.md)** — save the question, not the answer
- **[Durability & Temporal](durability.md)** — what happens to a two-hour batch when you deploy
- **[Products & releases](product-timeline.md)** — the version axis, and a ship that refuses
- **[Budgets & cost](budgets.md)** — what this costs, and the levers that matter
- **[Notifications](notifications.md)** — how you find out, without watching

The through-line: a number nobody looks at changes nothing. Each page here is about closing the loop
between a scorecard and a decision.
