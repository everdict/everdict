# site/ — the public web presence (homepage + documentation site)

A Docusaurus 3 app that publishes the repository's `docs/` tree, plus the hand-written marketing
homepage served at `/`.

Deployed to **GitHub Pages** by `.github/workflows/docs.yml` on every push to `main` that touches
`docs/**` or `site/**`.

## Run it

```bash
cd site
pnpm install --ignore-workspace   # site is NOT a pnpm-workspace member — see below
pnpm dev                          # http://localhost:3000/everdict/
pnpm build && pnpm serve
```

## How it is wired

- **Content is `../docs`, consumed in place.** The docs plugin's `path` points at the repository's docs
  tree; nothing is copied or synced, so there is exactly one source of truth and `docs/**` stays
  readable on github.com.
- **One plugin instance, three sidebars** — `guideSidebar` (autogenerated from `docs/guide`),
  `referenceSidebar` (hand-ordered over the root docs, runbooks and migrations), `internalsSidebar`
  (autogenerated from `docs/architecture`). One instance is deliberate: the tree cross-links heavily,
  and Docusaurus only resolves relative `.md` links *within* an instance.
- **`markdown.format: 'md'`** — the tree is plain CommonMark written for GitHub. Without this, MDX
  reads a literal `<total>` or `{...}` in prose as JSX and the build fails.
- **`onBrokenLinks: 'throw'`** — a dead link fails the build. GitHub Pages has no per-PR preview URL,
  so this build running on pull requests is what stops a broken docs change from merging.
- **Not a pnpm-workspace member.** `site` is absent from `pnpm-workspace.yaml` on purpose: adding it
  would pull Docusaurus into the root `turbo run build`/`typecheck` and change the repository's quality
  gate. It keeps its own `pnpm-lock.yaml` and installs with `--ignore-workspace`.

## Layout

- `docusaurus.config.ts` — site config; `DOCS_URL` / `DOCS_BASE_URL` env vars set the deploy target
- `sidebars.ts` — the three sidebars
- `src/css/custom.css` — the product's Linear-style indigo, light and dark
- `static/index.html` — the marketing homepage, served at `/` (plain HTML/CSS, no framework)
- `static/img/*.webp` — product screenshots, also used by the repository README

The homepage is a static file rather than a Docusaurus page, so Docusaurus does not know `/` is a
route; the navbar brand therefore uses an absolute href. That is why the link checker can stay strict.

## Custom domain

Set `DOCS_URL=https://<domain>` and `DOCS_BASE_URL=/` in `.github/workflows/docs.yml`, add the domain
in the repository's Pages settings, and commit a `static/CNAME`.
