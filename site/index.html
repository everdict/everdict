Point Everdict at the agent you already built and the data you already have.

1

Register

Version any harness — a CLI via a declarative command spec, or a multi-service topology — and a dataset of cases.

2

Run

Everdict executes it across your runtimes — isolated, reproducible — and collects the trace, cost, and outputs.

3

Questions, answered.

Which agent frameworks work?

Any. Everdict is harness-agnostic — Claude Code, Codex, LangGraph, or any CLI via a declarative command spec, or a deployed multi-service topology. No rewrite.

Is it really self-hosted?

Yes — fully. It runs on your Nomad, Kubernetes, Docker, or a laptop; isolation comes from your own runtime. Air-gap capable, bring your own models and keys. Apache-2.0.

What makes a score defensible?

Reproducible scorecards, deterministic graders (tests / cost / latency / steps), LLM/VLM/agent judges, pass@k trials, and baseline↔candidate diffs — with the full trace behind every number.

How do agents and CI use it?

People use the web; agents and CI use the OAuth-protected MCP server or an API key — same tools, role-gated and workspace-scoped. Gate a PR from your pipeline.
